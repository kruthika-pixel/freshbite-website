# freshbite-website
A responsive food ordering website designed for a simple and user-friendly online food ordering experience.
FreshBite - Food Ordering Website

Project Overview:

FreshBite is a food ordering website developed as part of my web development internship project. The website is designed to give users a simple and convenient way to explore restaurants, view food items, and navigate through different sections related to online food ordering.

The project focuses on creating a clean website structure with separate pages for different user requirements, including restaurants, menus, products, user registration, login, account details, and contact information.

Objectives

The main objectives of this project are:

- To create a simple and user-friendly food ordering website.
- To provide separate sections for restaurants, menus, and food products.
- To create basic user registration and login pages.
- To organize the website into multiple connected pages.
- To provide easy navigation between different sections.
- To create a website structure that can be further developed into a complete online food ordering system.

Technologies Used

- HTML5
- CSS3
- JavaScript

Website Pages

1. Home Page

The home page acts as the main entry point of the website. It provides an introduction to FreshBite and navigation to the other sections of the website.

2. About Page

The About page provides information about the FreshBite website and its purpose.

3. Restaurants Page

The Restaurants page is used to display restaurant-related information and allows users to explore available restaurants.

4. Menu Page

The Menu page contains food-related sections where users can browse available menu items.

5. Product Page

The Product page provides information about individual food products.

6. Login Page

The Login page provides an interface for existing users to enter their login details.

7. Register Page

The Register page provides a form for new users to create an account.

8. Account Page

The Account page is intended for displaying user account-related information.

9. Contact Page

The Contact page provides a section through which users can find contact-related information.

How to Run the Project

Method 1 - Using a Web Browser

1. Download or clone this repository.
2. Open the project folder.
3. Locate the "index.html" file.
4. Double-click "index.html".
5. The website will open in your default web browser.
6. Use the navigation links to visit the different pages.

Method 2 - Using Visual Studio Code

1. Download the project repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html".
4. Run the file using a web browser or the Live Server extension.
5. Navigate through the website and test the available pages.

Project Workflow

The website starts from the home page and provides navigation to different sections. 
Users can browse restaurant and menu information, view products, and access account-related pages.

The registration and login pages provide the basic interface required for user account management. 
The different pages are connected through navigation links to make movement between sections easier.
